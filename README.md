# 🔗 URL Shortener Bot

Telegram бот для сокращения длинных ссылок с отслеживанием кликов.

## ✨ Возможности

- **Сокращение ссылок** - Быстрое создание коротких кодов
- **Кастомные алиасы** - Создание memorable кодов
- **Статистика кликов** - Отслеживание количества переходов
- **История ссылок** - Просмотр всех созданных ссылок
- **Расшифровка** - Получение оригинальной ссылки по коду

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd url-shortener-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env`:
```bash
cp .env.example .env
```

4. Добавьте токен бота в `.env`:
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
BITLY_API_KEY=your_bitly_api_key_optional
BITLY_LOGIN=your_bitly_login_optional
```

## 🚀 Запуск

### Локально (polling):
```bash
python src/bot.py
```

### На Vercel (webhook):
1. Разверните на Vercel
2. Установите webhook:
```bash
curl -F "url=https://your-app.vercel.app/api/webhook" https://api.telegram.org/bot<YOUR_TOKEN>/setWebhook
```

## 💡 Примеры использования

### Сокращение ссылки (случайный код):
```
https://example.com/very-long-url
```

### Сокращение ссылки (кастомный код):
```
https://example.com mylink
```

### Расшифровка ссылки:
```
/mylink
```

### Просмотр статистики:
Нажмите кнопку "📊 Моя статистика" в меню

## 🎨 Особенности

- **Автоматическая генерация кодов** - 6-символьные случайные коды
- **Кастомные коды** - 3-10 символов, только буквы и цифры
- **История** - Все созданные ссылки сохраняются
- **Персональная статистика** - Данные по каждому пользователю

## 🔧 Настройка

### Bitly API (опционально)
Для интеграции с Bitly для глобальных сокращений:
1. Зарегистрируйтесь на bitly.com
2. Получите API ключ
3. Добавьте в `.env`

Без Bitly бот работает с локальной базой данных.

## 📊 Формат кодов

- Случайный: 6 символов (a-z, A-Z, 0-9)
- Кастомный: 3-10 символов, только буквы и цифры
- Примеры: `abc123`, `mylink`, `promo2024`

## ⚠️ Примечания

- Ссылки хранятся локально в JSON файле
- Для продакшена рекомендуется использовать базу данных (PostgreSQL, MongoDB)
- Коды уникальны в пределах базы данных
